# Elo Solidário

Plataforma web para ONGs divulgarem projetos, receberem doações e cadastrarem voluntários.
Trabalho da disciplina de desenvolvimento web, Entrega II (CSS3).

## O que foi feito

- Design system com variáveis CSS (cores, fontes e espaçamentos) em `css/variaveis.css`
- Layout geral com CSS Grid e componentes com Flexbox
- Grid de 12 colunas em `css/grid.css`
- 5 breakpoints: 480px, 640px, 768px, 1024px e 1280px
- Menu com dropdown e menu hambúrguer no celular
- Cards de projetos, botões com hover, focus, active e disabled, formulários com validação visual
- Alertas, toast, modal, badges e tags
- Página `componentes.html` mostrando tudo que foi criado

## Pastas

```
ong-elo-solidario/
  index.html
  pages/   (projetos, voluntario, doacao, contato, componentes)
  css/     (style.css importa os outros arquivos)
  js/      (script.js: modal, toast e formulários)
  img/
```

## Como abrir

Baixar o projeto e abrir o `index.html` no navegador.

## Observações

- Os formulários não enviam nada de verdade, só mostram uma mensagem.
- Nomes, números e endereço são fictícios.
